KORMORAN LABS — LOGO PACK v1
=============================

SYMBOL  (svg/ = vector master, png/ = ready-to-use images)
- kormoran-mark-on-dark ........ Moonbone mark, emerald eye. For dark backgrounds.
- kormoran-mark-on-light ....... Abyss mark, deep emerald eye. For light backgrounds.
- kormoran-mark-black / -white . One-colour versions (stamps, engraving, embossing, foil).
- kormoran-mark-small-* ........ Simplified mark for sizes under 40 px (no scanlines).
- favicon.svg / favicon.ico / favicon-16/32/48.png ... website tab icon.
- apple-touch-icon-180.png, app-icon-1024.png ......... phone and app icons.
The bird is a true cut-out (transparent), so the mark sits on any background.


THE NAME
KORMORAN ... Syne Bold (700), all capitals, letter-spacing +220 (0.22 em)
Labs ....... Cormorant Garamond Medium Italic (500), about 115% of the
             KORMORAN size, same baseline, gap of about 0.35 em
Tagline .... Cormorant Garamond Italic
Labels ..... JetBrains Mono, capitals, letter-spacing +140 to +160

All three typefaces are free under the SIL Open Font License,
commercial use included:
  https://fonts.google.com/specimen/Syne
  https://fonts.google.com/specimen/Cormorant+Garamond
  https://fonts.google.com/specimen/JetBrains+Mono


LOCKUPS  (svg/lockups-live-text/)
Horizontal and stacked logo + name, dark and light. The name is live text:
it displays correctly in a web browser and in Figma (Google Fonts are built in).
For a final print master: install Syne and Cormorant Garamond, open the file,
and convert the text to outlines (Figma: Flatten, Illustrator: Create Outlines).


COLOURS

Deep Water   #0F171C   panels, cards
Tide         #2A3940   hairlines only, never text
Mist         #8E9AA0   secondary text on dark
Slate        #4E5A60   secondary text on light
Moonbone     #E9E6DF   the moon, text on dark
Emerald Eye  #3CF0B4   the only accent
Emerald Deep #097052   the eye on light backgrounds


RULES
- Clear space around the mark: at least a quarter of its diameter.
- Minimum size: full mark 40 px / 12 mm. Below that, use the small version.
- The eye is the only colour. Don't recolour the bird, stretch, rotate,
  outline or add effects to the mark.
